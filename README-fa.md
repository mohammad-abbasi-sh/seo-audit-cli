# seo-audit-cli

**ممیزی فنی سئو برای هر URL — بدون هیچ وابستگی، با یک دستور و یک امتیاز.**

```bash
python seo_audit.py https://example.com
python seo_audit.py https://example.com --json -o report.json
```

بدون `pip install`، بدون API key. فقط استانداردلایب پایتون ۳٫۱۰ به بالا.

## چه چیزی را چک می‌کند

| چک | چرا مهم است |
| --- | --- |
| وضعیت HTTP و زمان پاسخ | صفحه‌ای که کند است یا ۲۰۰ نیست، نمی‌تواند رتبه بگیرد |
| Title (وجود + طول) | سیگنال اصلی رتبه و CTR |
| Meta description (وجود + طول) | CTR در صفحه نتایج جستجو |
| دقیقا یک H1 | ساختار سند برای خزنده‌ها و پاسخ‌های هوش مصنوعی |
| تگ Canonical | کنترل محتوای تکراری |
| متای Robots | `noindex` تصادفی، قاتل خاموش ترافیک است |
| تگ‌های Open Graph | ظاهر صفحه موقع اشتراک‌گذاری |
| داده ساخت‌یافته JSON-LD (و `@type`های پیدا شده) | نتایج غنی و واجد شرایط بودن برای GEO / جستجوی هوش مصنوعی |
| پوشش alt تصاویر | دسترس‌پذیری + جستجوی تصاویر |
| تعداد کلمات، ساختار H2، دسته‌بندی لینک‌ها | یک بررسی سریع سلامت محتوا |

خروجی در پایان یک **امتیاز ۰ تا ۱۰۰** می‌دهد تا بتوانید یک صفحه — یا یک رقیب — را در طول زمان دنبال کنید.
